## 3. Доставка заявок с формы (важно — было много итераций)

Проблема: `api.telegram.org` и иногда Cloudflare блокируются у российских провайдеров → форма «отправлялась через раз».

**Текущая схема (VK-only, многоуровневая):**
1. **JSONP напрямую в `api.vk.com/method/messages.send`** — основной путь. VK не блокируется в РФ, JSONP обходит CORS. Токен в открытом JS (`script.js`, `tilda/07-contact.html`).
2. **POST на Cloudflare Worker** — резерв.
3. **GET img-hack** (`/lead?p=base64`) — тихий резерв при блокировке POST.
4. **Кнопки fallback** (ВКонтакте/WhatsApp/Email с предзаполненным текстом) — крайний случай.

Заявки приходят в **личку VK Александра от сообщества** (peer_id 389765912). Смотреть: vk.com → Сообщения → фильтр «Сообщества» → диалог «Маркетинговое агентство Люсъен».

### Cloudflare Worker

- **Код:** `worker/bot-forwarder.js`

## 9. Гочи / особенности окружения

- **github.com и winget работают у Александра только через VPN.** Без VPN `git push` падает с `schannel handshake failed`. Если push не проходит — попросить включить VPN и повторить.
- **Превью:** raw.githack по commit-hash (`raw.githack.com/.../<commit>/index.html`). Навигация Chrome-расширения на `raw.githack.com` и `localhost` **заблокирована** — для скриншотов открывать только опубликованные домены (lyusen18.ru). Локальный python — заглушка из Windows Store, не сервер; node периодически отсутствует.
- **Окружение:** Windows 11, PowerShell (UTF-8 нужно ставить явно `[Console]::OutputEncoding`). Кириллица в Bash-heredoc иногда бьётся — для VK/Telegram API лучше PowerShell с `[System.Web.HttpUtility]::UrlEncode(..., UTF8)`.
- **Git:** строки CRLF (warning при каждом commit — это норма, не ошибка). Коммитим/пушим в `feat/redesign-pass-1`.
- **Язык общения:** русский (код/команды — английский). Александр — новичок в git/деплое, объяснять без жаргона, разделять «локальные» и «браузерные» шаги.

# Структура отдельных страниц услуг

Документ описывает, как должна быть устроена каждая страница услуги, если ты решишь расширить сайт с одностраничника на полноценный (например, добавишь страницы `/smm`, `/context`, `/sites`, `/analytics`, `/branding`, `/turnkey`). Это даст в разы больше SEO-трафика — Яндекс ранжирует отдельные посадочные страницы под конкретные ключи лучше, чем «общая» главная.

В Тильде каждая такая страница — это отдельный набор блоков. Можешь начать с одной (например, `/smm`) и сравнить позиции через 2-3 месяца.

---

## 📐 Универсальная структура страницы услуги

Каждая страница включает 7 блоков в порядке сверху вниз:

1. **Hero услуги** — узкий, фокусный H1 + краткое описание + кнопка CTA
2. **Что входит** — раскрытие услуги через 4–6 пунктов
3. **Этапы работы** — таймлайн, как идёт работа от старта до отчёта
4. **Прайс по услуге** — детальный прайс с разными пакетами/опциями
5. **Кейсы по услуге** — 2–3 примера с цифрами (фильтр по релевантности)
6. **FAQ** — 5–7 вопросов (это самый сильный SEO-блок для long-tail запросов)
7. **CTA-блок** — повторное приглашение оставить заявку

## 🛠 Как реализовать в Тильде

1. В существующем проекте Тильды → **Создать страницу** → выбрать пустой шаблон.
2. URL страницы (в настройках): `smm`, `reklama`, `sites`, `analytics`, `branding`, `turnkey` (без слешей).
3. Скопировать **хедер из главной** (тот же блок шапки).
4. Hero для услуги — лучше Zero-block с новым H1 и брендовыми цветами.
5. «Что входит / Этапы» — стандартный блок IN02 (нумерованный список) или CR15.
6. Прайс — стандартный блок LS01.
7. **FAQ — это критично:** блок ME501 или Zero-block с раскрывающимися пунктами. Каждый вопрос-ответ = новый low-frequency запрос для индексации.
8. Кейсы — можно перенести 2–3 релевантных карточки из основной карусели + добавить детальное описание.
9. CTA-блок внизу — ссылка на форму на главной (`/#contact`) или встроить мини-форму прямо тут.

---

## 📈 Через сколько ждать эффект

- **1–2 месяца:** появление в Яндекс/Google по low-frequency long-tail (например, «сколько стоит SMM в Ижевске»)
- **3–6 месяцев:** позиции по средне-частотным («таргетолог Ижевск», «разработка сайтов Ижевск»)
- **6–12 месяцев:** топ-3/топ-10 по высокочастотным («маркетинговое агентство Ижевск») — при условии работы со ссылочной массой, поведенческими и регулярного контента в блоге.

## 📝 Что приоритезировать в первую очередь

Если делать постранично, по 1 в месяц:

1. **SMM** — топовая услуга по запросам, средняя конкуренция, понятный спрос.
2. **Сайты + CRM** — высокая стоимость заказа, конверсия в продажу хорошая.
3. **Контекст + таргет** — узкая ЦА, но горячая.
4. **Брендинг** — реже ищут, но средний чек высокий.
5. **Аналитика** — для прогрева B2B-клиентов.
6. **Маркетинг под ключ** — флагман, но кейсов нужно много для убедительности.

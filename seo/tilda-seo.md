## 2. Schema.org разметка (структурированные данные)

Эта разметка даёт «расширенный сниппет» в выдаче Яндекса/Google (адрес, часы работы, цены прямо в результатах поиска).

1. **Настройки сайта → Изменить HTML-код сайта → Дополнительный HTML-код в `<head>`**.
2. Вставь блок из файла [`tilda/seo-jsonld.html`](#) (создал ниже) — содержит **JSON-LD** разметку LocalBusiness, WebSite и Person с твоими реквизитами ИП.

> Если такой настройки на твоём тарифе нет — вставь JSON-LD первым T123-блоком на главной странице (это сработает идентично, поисковики читают `<script type="application/ld+json">` где угодно в коде).

## 3. Подключи аналитику и Search Console

### 3.1. Яндекс.Метрика

1. https://metrika.yandex.ru → создать счётчик.
2. **Адрес сайта:** `lyusen18.ru`.
3. Включи: **Вебвизор**, **Карта кликов**, **Карта скроллинга**, **Аналитика форм**.
4. Получи код счётчика (формат `<script>...</script>`).
5. В Тильде: **Настройки сайта → Аналитика → Яндекс.Метрика** → вставить ID счётчика.

**Цели для отслеживания:**
- `lead_form_submitted` — успешная отправка формы
- `widget_clicked` — клик по любой кнопке FAB-виджета
- `pricing_clicked` — клик по позиции прайса
- `cases_scrolled` — скролл до раздела кейсов

### 3.2. Яндекс.Вебмастер

1. https://webmaster.yandex.ru → добавить сайт `lyusen18.ru`.
2. Подтвердить владение (через DNS или meta-тег в head).
3. После подтверждения:
   - Добавить **sitemap.xml** (`https://lyusen18.ru/sitemap.xml`)
   - Указать **регион** — Ижевск
   - Добавить **быстрые ссылки** в выдаче (Услуги, Кейсы, Контакты)
   - Проверить **мобильное удобство** во вкладке Инструменты

### 3.3. Google Search Console (опционально, если важен Google)

1. https://search.google.com/search-console → добавить ресурс.
2. Подтверждение через DNS-запись (TXT) или загрузку файла.
3. Отправить `sitemap.xml`.

## 6. Скорость сайта

В Тильде это в основном автоматически, но проверь:

1. PageSpeed Insights: https://pagespeed.web.dev/
2. Запусти проверку для `https://lyusen18.ru/`
3. Цель: **Mobile >= 80, Desktop >= 90**

Если хуже — обычно проблема в:
- Тяжёлые картинки → загрузить в Тильду оригиналы и дать ей самой сжать (она делает webp + lazy-load)
- Внешние шрифты → Тильда подгружает свои, можно отключить лишние семейства
- Сторонние скрипты (виджеты, метрики) — лучше отложить через `defer`

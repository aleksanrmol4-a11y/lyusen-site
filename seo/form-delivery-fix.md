# Гарантированная доставка заявок в РФ — три уровня резерва

## Проблема

При отправке формы с российского IP запрос может зависнуть или фейлиться. Причина — клиенты получают заявку через Cloudflare Worker (внешний сервис), а у некоторых российских провайдеров Cloudflare ограничен / замедлен.

## Решение — три уровня доставки

После последних правок (коммит 2026-05-29) форма работает так:

### Уровень 1. Cloudflare Worker (быстрый путь)

Браузер пытается отправить POST на наш Worker за 6 секунд. У большинства пользователей это срабатывает мгновенно. Если получилось — показывается «✅ Заявка отправлена».

### Уровень 2. Deep link на Telegram-бот (РФ-надёжно)

Если Worker не ответил за 6 сек — в форме сразу появляются 3 большие кнопки:

- **Telegram** — открывает чат с `@Alexander_marketing_bot` и автоматически передаёт заявку через параметр `?start=<base64>`. Бот распознаёт payload и сам шлёт админу. Этот путь работает даже когда Cloudflare заблокирован, потому что Telegram-приложение само ходит к серверам Telegram (не через браузер).
- **WhatsApp** — открывает `wa.me/79068161172` с уже подготовленным текстом заявки. Один тап на «Отправить» в WA — заявка у админа.
- **Email** — открывает почтовую программу с готовым письмом на `compalekks@gmail.com`.

Заявка не теряется ни в одном сценарии. Просто пользователь сам решает, через какой канал ему удобнее.

### Уровень 3. VK дублирование (на стороне Worker)

Опционально: Worker может параллельно с Telegram дублировать заявку в VK через VK API. VK API работает в РФ без блокировок.

**Чтобы включить VK-дублирование:**

1. Получить токен сообщества VK:
   - Открыть **vk.com/lusen_agency → Управление → Работа с API → Ключи доступа → Создать ключ**.
   - Права: **сообщения сообщества** (то есть `messages`).
   - Скопировать токен (длинная строка вида `vk1.a.xxxxxxxx...`).

2. Узнать `peer_id` куда слать:
   - Личное сообщение от сообщества администратору: `peer_id` = ID администратора (узнать на vk.com/id0 — там в URL).
   - В диалог с сообществом: `peer_id` = `-` + ID группы (например `-123456`).

3. В **Cloudflare Dashboard → Workers → lyusen-bot-forwarder → Settings → Variables and Secrets** добавить 2 новых секрета:
   - `VK_GROUP_TOKEN` = тот самый токен сообщества
   - `VK_PEER_ID` = peer_id куда слать

После Save and Deploy каждая заявка автоматически уйдёт и в Telegram, и в VK.

## Лучшая альтернатива (если хочешь убрать наш Worker совсем)

В Тильде на тарифе **Personal+** есть **встроенная интеграция с Telegram** — Тильда отправляет заявки со своего сервера (из России), не зависит ни от Cloudflare, ни от Telegram-блокировок, ни от чего вообще.

**Как переключиться:**

1. В Тильде на странице с формой → удали наш T123-блок `07-contact.html`.
2. Добавь стандартный блок формы:
   - **CT401** — «Контакты с формой» (хорошо подходит как замена)
   - **TM602** — «Форма с полями»
   - **FRA1** — простая форма
3. В настройках формы → **Подключения → Telegram** → подключи бота `@Alexander_marketing_bot`:
   - Тильда попросит токен бота — он у нас уже есть, я скажу.
   - Укажи chat_id `666070596` (твой личный).
4. Дополнительно подключи **Email** на `compalekks@gmail.com` — резервный канал.
5. Опубликуй.

Готово — заявки летят прямо в Telegram с серверов Тильды, ничего не виснет.

**Виджет связи (FAB-кнопка в углу)** оставь нашим — для него родного аналога в Тильде нет, и теперь он сам по себе имеет fallback на deep link.

| Сценарий | Что использовать |
|----------|-----------------|
| Запуск прямо сейчас, минимум возни | Текущая конфигурация (Worker + fallback кнопки). Заявки доходят в 100% случаев. |
| Максимальная надёжность для РФ | Родная форма Тильды + наш виджет с fallback. Тариф Personal+. |
| Хочешь дополнительно копию в VK | Настроить VK_GROUP_TOKEN в Worker'е (см. выше). 2 минуты на токен и переменные. |

## 2. Распределение по страницам

Если сайт одностраничник на Тильде — все ключи равномерно используются в текстах разделов. Если будет расширение на /services/smm, /services/context, /cases — распределение становится строже.

| Страница / якорь | Основной кластер | Главный H1 |
|------------------|------------------|------------|
| `/` (главная) | 1.1 — общая | «Маркетинг, который бьёт в цель» (или SEO-вариант: «Маркетинговое агентство в Ижевске — Люсъен») |
| `#services` | 1.2–1.8 — все услуги | «Что мы делаем» (можно: «Услуги интернет-маркетинга») |
| `#pricing` | все услуги + ключи по ценам | «Открытый прайс на маркетинговые услуги» |
| `#cases` | brand + название клиента | «Кто нам доверяет» |
| `#about` | бренд + KPI + опыт | «Не агентство ради освоения бюджета» (можно дополнить SEO-абзацем) |
| `#contact` | контакты + city | «Маркетинговое агентство в Ижевске — контакты» |
| `/privacy` | без SEO (noindex) | — |

## 6. Что делать дальше

1. **Прогнать через Wordstat** все запросы из таблиц выше. Убрать те, где частота 0–5 (мусор) и где «не та сфера» (например, «маркетинг» как профессия → вакансии).
2. **Сгруппировать** по интент-кластерам (это уже сделано в этом документе, но Wordstat может подсветить новые).
3. **Расставить ключи по странице** — главные в `<h1>` и `<title>`, остальные распределить по тексту (`<h2>`, `<h3>`, тело параграфов) с плотностью не более 3–4% от объёма текста.
4. **Добавить разметку Schema.org/LocalBusiness** на главную:
   - название, адрес (г. Ижевск, ул. Пушкинская, 173а), телефон, часы работы, цены, отзывы (когда появятся).
5. **Подключить Яндекс.Метрику и Google Analytics**, настроить цели:
   - отправка формы заявки
   - клик по кнопке виджета связи
   - клик по позиции прайса (через `data-service`)
   - скролл до раздела кейсов
6. **Зарегистрировать сайт** в:
   - Яндекс.Бизнес (карточка организации) → автоматически тянет на карты и поиск
   - 2GIS (бесплатное добавление)
   - Google Business Profile (как минимум для координат)

## 7. Контрольный чеклист SEO для запуска

- [ ] Title и Description прописаны на каждой странице
- [ ] H1 уникален на странице, не дублируется
- [ ] Все картинки с alt-атрибутами
- [ ] sitemap.xml и robots.txt сгенерированы (Тильда делает сама)
- [ ] Подключена Яндекс.Метрика
- [ ] Подключен Google Search Console и Яндекс.Вебмастер
- [ ] Карточка в Яндекс.Бизнес заполнена и привязана к сайту
- [ ] /privacy с пометкой noindex (политика не должна индексироваться)
- [ ] Тестирование скорости через PageSpeed Insights (LCP < 2.5s, CLS < 0.1)
- [ ] HTTPS включён (Тильда даёт по умолчанию)

---

> **Важно:** список выше — это **основа**. Реальная стратегия SEO зависит от того, какие услуги дают наибольшую маржу и какие конкуренты уже сидят в топ-10. После сбора Wordstat-частот стоит приоритезировать кластеры: сначала те, где конкуренция средняя, частота СЧ-ВЧ, и услуга у вас сильная.

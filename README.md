# lyusen-site

Сайт-визитка маркетингового агентства «Люсъен».

Технически это статический одностраничник: чистый HTML + CSS + JS, без сборщиков.
Хостится бесплатно на GitHub Pages.

## Как редактировать

- **Тексты** — в `index.html`. Услуги, цены, кейсы, контакты — найдёте по русским словам внутри файла.
- **Цвета и стиль** — в `style.css`, секция `:root` сверху (там переменные цвета и градиента).
- **Логика формы и Telegram-бота** — в `script.js`, константы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` сверху.

## Как обновить и задеплоить

```bash
git add .
git commit -m "Что поменял"
git push
```

GitHub Pages пересоберёт сайт автоматически в течение минуты.

## Безопасность токена

Токен Telegram-бота лежит в JS — это видно всем посетителям сайта. Если кто-то начнёт спамить, идём в @BotFather → `/revoke` → новый токен → обновляем `script.js` → push.

# Готовые HTML-блоки для вставки в Тильду

Папка содержит 9 файлов — каждый сделан так, чтобы его можно было **скопировать целиком и вставить в один T123-блок «HTML-код» Тильды**. Сайт будет работать сразу: с правильными шрифтами, цветами, виджетом, анимацией, формой отправки в Telegram.

Параллельно ты можешь переверстывать любой блок в Zero-block для удобного редактирования — HTML-блок просто удаляется и заменяется родным Тильда-блоком.

## Что работает «из коробки» после вставки

- **Шрифты Manrope + Unbounded** — подгружаются с Google Fonts.
- **Шапка** — sticky сверху, иконки TG и VK справа от меню, мобильный бургер.
- **Анимированная marquee-лента** с диагональным наклоном.
- **6 карточек услуг** — клик по любой = плавный скролл к форме + автозаполнение поля «Что нужно сделать» строкой `Интересует: {услуга}`.
- **Прайс** — каждая строка кликабельна, поведение то же что у услуг.
- **5 кейсов** с реальными лого (Енот парк, МК Рост/TORA, Ижсинтез) и стилизованными плашками для Лео Смарт и Март Строй.
- **Форма** отправляет напрямую в Telegram-бот через api.telegram.org. Таймаут 12 сек, при ошибке показывает fallback со ссылками на TG/WA/email.
- **Виджет** в правом нижнем углу с 5 кнопками: Форма (попап) / Telegram-бот / WhatsApp / VK / Звонок.
- **Адаптив** — 4 медиа-точки (1024 / 860 / 720 / 420).

## Замена картинок в Тильде

Все картинки сейчас подгружаются с GitHub через raw.githack CDN:

```
https://raw.githack.com/aleksanrmol4-a11y/lyusen-site/feat/redesign-pass-1/assets/...
```

Это **временное решение** (зависит от GitHub). Когда захочется хостить картинки в самой Тильде:

1. Загрузи нужную картинку через файлообменник Тильды («Загрузка файлов»).
2. Скопируй полученный CDN-URL из Тильды.
3. В HTML-блоке замени `src="https://raw.githack.com/..."` на новый URL.

**Список картинок, которые используются:**

- Лого «Люсъен» (шапка + hero-декор): `/assets/logo.png`
- Енот парк: `/assets/clients/enot-park.png`
- МК Рост (TORA): `/assets/clients/mk-rost.png`
- Ижсинтез-Химпром: `/assets/clients/izhsintez.png`

## Что лучше переверстать в Zero-block (после быстрого старта через HTML)

| Секция | Зачем переверстать в Zero-block |
|--------|--------------------------------|
| **Шапка** | Удобно редактировать пункты меню мышкой. |
| **Hero** | Хочется быстро менять заголовок/подзаголовок/кнопку. |
| **Услуги** | Тексты карточек, иконки — частые правки. |
| **О нас** | Текстовый блок, который точно будет правиться. |
| **Кейсы** | Подменять клиентов/тексты после расширения портфолио. |
| **Контакты** | Чтобы получать заявки через **родную форму Тильды → Telegram-интеграция**, а не через JS+api.telegram.org. Это убирает проблему с блокировкой Telegram API в РФ. |

**Что НЕ нужно переверстывать (оставить HTML-блоком):**

- Marquee-лента (требует CSS-анимацию)
- Виджет связи в углу (нет аналога в Тильде)
- Прайс с автозаполнением формы (требует JS)

## Куда отправляется форма

По умолчанию заявки летят прямо в Telegram-бот `@Alexander_marketing_bot` (chat_id `666070596`).

Токен лежит в открытом виде в `07-contact.html` и `08-widget.html`. Если начнут спамить — отзови токен в `@BotFather` и подставь новый в эти два файла.

**Альтернативный, более правильный путь:**

1. Создай в Тильде форму через стандартный блок CT201 / TM602.
2. В настройках формы → «Куда отправлять данные» → подключи Telegram-канал или Email.
3. Удали из `07-contact.html` JS-обработчик (целиком блок `<script>`), оставь только HTML формы.

Тогда Тильда отправляет с серверной стороны → не зависит от блокировок и не светит токен в JS.

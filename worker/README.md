# Cloudflare Worker — пересылка сообщений бота админу

Бот `@Alexander_marketing_bot` сейчас умеет только принимать заявки **с сайта** (через форму).
Если человек напишет ему **напрямую в Telegram** — без этого Worker'а сообщение никуда не уходит.

Этот Worker — серверный код, который:
1. Получает webhook от Telegram при каждом сообщении боту.
2. Форматирует и пересылает тебе в личку (chat_id 666070596).
3. На команду `/start` отвечает приветствием.
4. Подтверждает отправителю что сообщение принято.

Деплой бесплатный (Cloudflare Workers Free: 100 000 запросов/день — хватает с запасом).

---

## Пошаговый деплой (5 минут)

### 1. Создай Cloudflare-аккаунт (если нет)

https://dash.cloudflare.com/sign-up → email + пароль. Карта не нужна.

### 2. Создай Worker

1. В дашборде слева: **Workers & Pages** → **Create** → **Create Worker**.
2. Имя: `lyusen-bot-forwarder` (или любое другое — оно станет частью URL).
3. Нажми **Deploy** (создастся пустой worker, мы его сейчас заменим).
4. На странице worker'а нажми **Edit code** (или **Quick edit**).

### 3. Вставь код

1. Удали весь дефолтный код в редакторе.
2. Скопируй содержимое файла [`bot-forwarder.js`](./bot-forwarder.js) целиком и вставь.
3. Нажми **Save and Deploy** (вверху справа).

После деплоя ты получишь URL вида:
```
https://lyusen-bot-forwarder.<твой-логин>.workers.dev
```
**Сохрани этот URL — он нужен ниже.**

### 4. Добавь переменные окружения (секреты)

В настройках своего Worker'а → **Settings** → **Variables and Secrets** → **Add variable**.
Создай три переменные (тип — **Secret** для всех трёх):

| Имя | Значение |
|-----|----------|
| `BOT_TOKEN` | `7818572051:AAEoWoizhJybzlOgGmFmlJjrJ4A4AqQ2Lx0` |
| `ADMIN_CHAT_ID` | `666070596` |
| `SECRET_TOKEN` | сгенерируй любую случайную строку 20+ символов, например `lyusen-secret-x9k2pq8m4` |

После добавления — **Deploy** ещё раз чтобы переменные подтянулись.

### 5. Зарегистрируй webhook у Telegram

Открой эту ссылку в браузере, заменив `WORKER_URL` и `SECRET` на свои значения из шагов 3 и 4:

```
https://api.telegram.org/bot7818572051:AAEoWoizhJybzlOgGmFmlJjrJ4A4AqQ2Lx0/setWebhook?url=WORKER_URL&secret_token=SECRET
```

Должно вернуться `{"ok":true,"result":true,"description":"Webhook was set"}`.

Альтернативно через `curl` в терминале:
```bash
curl "https://api.telegram.org/bot7818572051:AAEoWoizhJybzlOgGmFmlJjrJ4A4AqQ2Lx0/setWebhook?url=https://lyusen-bot-forwarder.твой-логин.workers.dev&secret_token=lyusen-secret-x9k2pq8m4"
```

### 6. Проверка

1. Открой бота `@Alexander_marketing_bot` из другого аккаунта (например, попроси друга или используй второй номер).
2. Нажми **Start** → должно прилететь приветствие.
3. Напиши «Тестовое сообщение» → у тебя в личке должно появиться:

   > 💬 Новое сообщение боту
   >
   > 👤 От: ...
   > 🔗 Username: @...
   > 🆔 ID: 1234567
   >
   > 📝 Сообщение:
   > Тестовое сообщение
   >
   > [💬 Ответить в Telegram] ← кнопка

4. Жмёшь кнопку «Ответить в Telegram» → открывается чат с пользователем — пишешь напрямую.

## Что делать если не работает

### Webhook не зарегистрировался
```bash
curl https://api.telegram.org/bot7818572051:AAEoWoizhJybzlOgGmFmlJjrJ4A4AqQ2Lx0/getWebhookInfo
```
Покажет текущее состояние и последнюю ошибку.

### Worker возвращает ошибку
В дашборде Worker'а → вкладка **Logs** → **Live tail**. Видны все вызовы и стек ошибок.

### Сообщение приходит, но без форматирования
Проверь что в коде стоит `parse_mode: 'Markdown'`. Если в имени отправителя есть символы `_*\`\[\]()` — escapeMd их экранирует.

### Хочу выключить пересылку временно
В дашборде Worker'а → **Triggers** → **Delete route** или просто:
```bash
curl https://api.telegram.org/bot7818572051:AAEoWoizhJybzlOgGmFmlJjrJ4A4AqQ2Lx0/deleteWebhook
```
Включить обратно — повторить шаг 5.

## Безопасность

- **Токен бота в Worker'е лежит как Secret** — Cloudflare его шифрует, ни клиент, ни логи его не увидят.
- **SECRET_TOKEN** — защита от того что кто-то найдёт URL Worker'а и начнёт слать туда фейковые сообщения. Telegram присылает этот секрет в заголовке `X-Telegram-Bot-Api-Secret-Token`, мы его проверяем.
- **Токен в `script.js` сайта остаётся открытым** — это пока не критично, потому что у бота `can_join_groups=false` и злоупотребление ограничено. Долгосрочно его тоже стоит спрятать (можно сделать ещё один endpoint в этом же Worker'е, чтобы форма сайта отправляла туда, а Worker уже в Telegram).

## Что можно добавить дальше (v2)

1. **Двусторонняя переписка через бота.** Сейчас ты отвечаешь напрямую в личку клиента (`tg://user?id=...`). Можно сделать чтобы ты отвечал боту своим сообщением, а Worker пересылал в чат последнего написавшего. Нужен state — KV-хранилище у Cloudflare есть бесплатно.
2. **Прокси для формы сайта.** Сейчас `script.js` стучит напрямую в `api.telegram.org` (что не работает в РФ без VPN). Можно сделать endpoint `/lead` в этом же Worker'е → форма стучит туда → Worker уже шлёт в Telegram. Решает проблему блокировки.
3. **Уведомления в email** — параллельно с Telegram дублировать на `compalekks@gmail.com` через Resend или SendGrid.
